# A11: registered forward confirmation of measurement efficiency

This registration precedes all A11 fitting and target measurements. Preparation is CPU only; the forward job will run on LONI later. No training or commits.

Design: four previously unmeasured Pythia source states: 160M at step 80000, 410M at step 112000, 1.4B at step 48000, and 1B at step 48000. Each is evaluated at retained densities 0.9, 0.85, 0.8, 0.75, 0.7, 0.65: 24 source-density cells per capability (math, code, QA), 72 scalar loss changes. All four states are absent from A9 summary.json development_rows and heldout_rows. Also exclude 160M/410M/1.4B at step 32000 and 1B at step 64000. This is a forward new-state confirmation conditional on the existing probe sets.

Development is the fixed nine-state panel: sizes 160M/410M/1.4B crossed with steps 16000/64000/143000, at densities 0.9/0.8/0.7/0.6 (36 measurements per capability). The reduced subset is fixed before fitting: densities 0.9 and 0.7 on EVERY development state, exactly 18 measurements per capability. This is A9's densities-axis 50 percent design with a deterministic rule, no random subset selection. All methods receive the same source metadata and dense anchors. Nine development dense anchors per capability are shared overhead, outside the 18/36 pruning budgets. Four new dense anchors per capability are measured in the forward job.

Register five predictors per capability: power_18, power_36, A2_36, median_curve_36, median_curve_18. Reuse analysis/a9_measurement_efficiency.py definitions. Source features are [1, z(log N0), z(L0,c), z(log D0)], with population mean/std fitted on selected development rows pooled across capabilities, separately for each budget. N0 is non-embedding decoder matrix count layers*(4*h*h+2*h*m); D0 is step*2097152 tokens. The five-parameter power form is Delta L = (beta dot features)*((1-d)/0.3)^gamma; unregularized least squares profiles gamma=0.50,0.55,...,6.00, minimum development SSE, increasing-grid tie break. A2 fits four source coefficients at each of four densities (16 parameters). Median curves use the per-density development medians. A2 and medians use adjacent linear interpolation in retained density and nearest-pair linear extension outside their anchors; median_curve_18 at 0.65 is therefore a registered extension. No target labels, held-out tuning, clipping, or refitting. Require the A9 rank checks (relative SVD tolerance 1e-10; power local Jacobian rank 5; A2 rank 4 per anchor).

Target reference losses L0,c are UNKNOWN. Freeze coefficients, standardizers, exact formulas and SHA256 before any target forward pass. For each source-conditioned cell register Delta L(L0,c)=a+b*((L0,c-mu_L)/sigma_L), with a,b fixed now. For each median cell register its numerical Delta L independent of L0,c. After the job, substitute only the dense reference loss measured for that state and capability in the SAME job. Predicted absolute loss, if reported, is L0,c+predicted Delta L. Dense measurements never tune coefficients, gamma, subset, or standardization.

Measurement: call analysis/v6_capability_geometry.py stage_prune through analysis/a11_measure.py. Reuse V6 bf16 loading, eval/no-grad forwards, global magnitude pruning of all language weight matrices including embeddings/head, NumPy default_rng seed 0, approximately 2000000 proportional weight samples, quantile threshold and strict abs(weight)>threshold. Every density restores from the same dense weights (GPU reference). V6 build_probes(128, seed=0), sequential MATH-500 test / MBPP full test / 2WikiMultihopQA validation sampling, selects odd indices [1::2], exactly 64 probes per capability. Freeze the rendered 128-probe sets in data/a11/probes.json and replay them through the unchanged evaluator. Loss is total completion-token NLL / total scored completion tokens, prompt masked, native tokenizer, 512-token prompt and 512-token completion limits, 1024 combined. Dense plus six pruning levels are measured together for each state; no reuse of earlier dense results.

Decision: analysis/a11_score.py computes unweighted MAE in nats over ALL 24 registered cells separately for each capability, for all five predictors. Primary efficiency support requires BOTH math and code to satisfy MAE(power_18)-MAE(A2_36)<=0.05 nats (one-sided noninferiority: improvements also qualify). Report paired MAE differences against A2_36 and both median curves, plus power_36. QA and whether MAE<=0.25 are descriptive, not extra gates. A median advantage must be reported and limits any claim of overall predictor superiority. Do not pool capabilities. No cell exclusion after seeing outcomes, alternate subsets, or post-hoc threshold changes. Missing, nonfinite, mismatched, or incomplete measurements leave the decision pending; never score a smaller panel as confirmation. This fixed four-state panel does not establish independent-seed or population uncertainty.

Frozen files are created exclusively. predictions.json.sha256 seals the exact prediction bytes; predictions.json includes the preregistration, plan, coefficient and runtime-file hashes. The job verifies these before loading models. Outputs live under results/a11-efficiency-confirmation/measurements/<state-tag>/; scoring writes summary.json and summary.md without changing predictions.json. Run: python -B analysis/a11_score.py. Sync with scripts/a11_sync_list.txt; submit scripts/loni_a11_prune.slurm separately on LONI. No GPU job is launched during preparation.
