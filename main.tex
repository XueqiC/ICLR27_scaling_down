\begin{abstract}
Capability-specialized agents rarely need frontier-scale generality: a
coding or retrieval agent needs a specific \emph{capability profile} at
the lowest deployment cost, usually obtained by compressing a dense
source model through pruning, quantization, or distillation with recovery
training. Choosing among these methods is today an expensive grid search,
because compression changes capabilities anisotropically and existing
scaling laws predict only aggregate loss within a single method. We
formulate \emph{capability-conditioned predictive scaling-down laws}: from
a dense source state observable \emph{before} compression (an observed
capability anchor plus public descriptors), common compression
coordinates, and a few method-specific controls, we predict the
post-compression capability vector and, from it, the cheapest
configuration meeting a workload requirement. Our central finding is an
asymmetry: \textbf{capability loss is a common \emph{outcome} coordinate,
with a map to behavioral accuracy shared across tested families, whereas
compression ratio is \emph{not} a common \emph{intervention} coordinate.}
Across twelve checkpoints from four families (Gemma-3/4, Muse, OLMo-3,
Qwen-3; 270M--32B), method-agnostic laws on storage and active-parameter
ratios fail to extrapolate across methods (at matched storage, a budget
near-lossless under quantization is catastrophic under pruning), whereas
method-specific laws reveal family-dependent cliffs, capability-specific
transfer, and data-dependent recovery. We therefore unify not the
interventions but the decision layer, as a capability- and cost-aware
\emph{method-selection map}. Held-out law fits and selection validation
are in progress and marked as such; no unverified result is stated as
fact.
\end{abstract}
