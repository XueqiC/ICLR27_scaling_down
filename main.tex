\begin{abstract}
Capability-specialized agents rarely need frontier-scale generality: a
coding or retrieval agent needs a specific \emph{capability profile} at
the lowest deployment cost, usually obtained by compressing a dense
source model through pruning, quantization, or distillation with recovery
training. Choosing among these methods today usually means an expensive grid
search: compression changes capabilities anisotropically, and existing
scaling laws predict aggregate loss within a single method. We
systematically investigate whether the model state observable
\emph{before} compression, together with the intervention configuration,
can predict the capability-conditioned loss after pruning, quantization,
and distillation, testing source-state transfer and unseen-configuration
prediction separately, with the per-capability conditional loss vector
as the common prediction endpoint. On a controlled panel, a
source-conditioned pruning predictor predicts unseen compression
densities with far lower error than strength-only baselines. A
same-input comparison, however, shows no additional advantage for a
shared power form. The predictive gain of the quantization candidate depends on the
precision regime, and damage-magnitude transfer under aggressive
quantization remains unstable. For distillation, the reuse-count coordinate improves QA-loss
prediction on an unseen data pool; for math and code it does no better
than a constant baseline, and it carries a budget-dependent bias. Across twelve checkpoints from four families (270M--32B),
method-agnostic laws on storage and active-parameter ratios did not
extrapolate across the methods we tested. These results delimit the
information the current predictors need, the range over which they
transfer, and their limits, providing tested candidate relations and an
evaluation basis for developing capability-conditioned scaling-down
laws.
\end{abstract}
