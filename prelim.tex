\section{Problem Formulation}
\label{sec:prelim}

\subsection{Capability vector and observables}

We fix a capability set $\capset$ (here mathematical reasoning, code
generation, multi-hop QA) and give each capability $c$ a probe set
$\probeset{c}$ of prompt--reference pairs from held-out benchmark
splits, cross-benchmark disjoint from all transfer and recovery data
(math: GSM8K/MATH-500/SVAMP; QA: HotpotQA/2Wiki/TriviaQA; code:
HumanEval/MBPP, with a third independent benchmark planned). The
primary observable is the capability-conditional task loss
\begin{equation}
\Lc{c}(w) \;=\; \frac{1}{T_c}\sum_{(x,y)\in\probeset{c}}
\sum_{t=1}^{|y|} -\log p_w\!\left(y_t \mid x, y_{<t}\right),
\label{eq:taskloss}
\end{equation}
continuous by construction \citep{schaeffer2024predicting,
gadre2024language}. Within-model compression deltas
$\Delta\Lc{c}$ compare a model to itself and are tokenizer-consistent;
any cross-family comparison of absolute levels uses tokenizer-normalized
units (bits or nats per byte). Task success enters only through a
separately validated monotone link $A_c=g_c(\Lc{c})$
\resultpending{held-out validation of $g_c$ on compression
configurations}. Probe sets are split once into estimation and
measurement halves so mechanism statistics and evaluations never share
sampling noise.

\subsection{Three layers of prediction inputs}
\label{sec:params}

All prediction-time inputs must be available before compression, cheap
to obtain, well defined, and public for open models.

\paragraph{1. Source-model descriptors.}
$\mathbf x_0=(N_0,\,D_0,\,f,\,a,\,\mathbf L_0^{\mathrm{obs}})$:
non-embedding parameter count, pretraining tokens where disclosed,
family, a few architecture descriptors, and the \emph{observed dense
capability anchor} $\mathbf L_0^{\mathrm{obs}}$---the capability vector
measured once on the dense model. The anchor absorbs data quality,
optimization, and post-training history that metadata cannot capture;
the practical prediction setting is
\begin{equation}
\hat L_c^{(m)} \;=\; L_{c,0}^{\mathrm{obs}}
\;+\; \widehat{\Delta L}_c^{(m)}(\mathbf x_0,\mathbf z_m,
\boldsymbol\theta_m).
\label{eq:anchored}
\end{equation}
Descriptors with insufficient independent variation in the grid
($D_0$ is largely confounded with $f$ in public families) are kept
only if they improve held-out prediction.
\resultpending{dense-reference comparison D1--D4 and the
$(N,D)$-identification grid}

\paragraph{2. Common compression coordinates.}
$\mathbf z_m=(r_{\text{active}},\,r_{\text{storage}},\,
r_{\text{compute}},\,D_A)$: active-parameter ratio, storage ratio,
theoretical inference-compute ratio, and post-compression adaptation
tokens---computable from the configuration alone, and the coordinates
on which cross-method comparison and any shared law must live.

\paragraph{3. Method-specific controls.}
$\boldsymbol\theta_m$: pruning (density $\dens$; pattern and criterion
fixed to global magnitude as the canonical protocol), quantization
(bit-width $\bits$; per-output-channel symmetric RTN, weights only),
distillation (student size $N_S$, trace tokens $\Ds$, teacher
capability vector $\mathbf L^{\mathcal T}$, supervision recipe
$\rho$), recovery (tokens $\Dr$, data source $\rho_R$, fixed LoRA
update recipe). Algorithmic choices that are not axes of the law are
frozen, not fitted.

Gradient, Fisher, deleted-mass, and alignment quantities appear in
this paper only as \emph{mechanism analysis} (\S\ref{sec:geometry})
and as upper-bound comparators for the reduced-form laws; they are
not prediction-time inputs.

\subsection{Workloads and the selection problem}

A workload $W$ specifies a requirement vector $\mathbf r_W$ over
$\capset$ and a link $S_W=G_W(\mathbf L,\mathbf r_W)$ from capability
losses to agent success, calibrated on a subset of workloads and
tested on held-out tasks and configurations
\resultpending{agent-level validation}. The decision problem the laws
serve is
\begin{equation}
\arg\min_{m,\boldsymbol\theta_m} C_m(\boldsymbol\theta_m;H)
\quad\text{s.t.}\quad
G_W\!\big(\hat{\mathbf L}^{(m)},\mathbf r_W\big)\ge S_W^{\min},
\label{eq:decision}
\end{equation}
with $C_m$ covering storage, inference compute, measured latency where
supported, and recovery training cost; unstructured-pruning parameter
reductions are not assumed to yield real latency gains.
