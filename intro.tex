\section{Introduction}
\label{sec:intro}

Deployed language-model agents are specialists. A coding agent lives
on code synthesis and tool use, a retrieval assistant on multi-hop
question answering, and both pay for every token of inference. The
model that serves such a workload is usually not a frontier model but
a dense source scaled down by pruning, quantization, or distillation,
and choosing the route and its strength today means running each
candidate configuration through capability benchmarks.

That search cannot be replaced by a single compression ratio, because
compression does not shrink capabilities uniformly. On twelve public
models from five series, the same pruning density leaves QA the
least-damaged capability in Qwen3 and OLMo-3-32B, where it improves,
and the most-damaged one in the Gemma series; damage at the same
density spans two orders of magnitude across series, and 3-bit
quantization collapses twelve of fourteen models but not OLMo-3-32B
(Appendix~\ref{sec:app_hetero}). Predicting what survives requires
both the initial model state and a per-capability endpoint.

We therefore ask how the capability-conditioned loss after compression
can be predicted from the initial model state and the configuration of
the method. The endpoint is the conditional loss of each capability
on a fixed probe set, and every prediction is written relative to a
reference measured beforehand, the dense source for pruning and
quantization and the initial student for distillation
(Eq.~\eqref{eq:interface}). The admitted inputs are the parameter
count, the pretraining token count where disclosed, the dense
capability losses of the reference, and the intervention setting; no
measurement of the compressed target enters a prediction.

The relations are developed on a controlled panel of Pythia checkpoints
whose size and pretraining stage vary independently, by comparing
low-dimensional functional forms that use the same inputs, and they are
tested by freezing coefficients and predictions before new
configurations and new model states are measured. This separates
three questions that a single accuracy number blurs: whether the
initial-state inputs help, whether a particular functional form adds
anything over a same-input alternative, and how far the relation
transfers.

The outcome is a set of method-specific empirical relations with
measured ranges. For pruning, a five-parameter power form in the
removed fraction with a source-conditioned amplitude predicts math and
code at unseen densities inside the fitted range, ties a per-density
regression, and fails beyond the range and for QA. For quantization,
bit-width alone supports only a per-bit source regression, but with
the quantization group size as a second axis a low-order form predicts
unseen bit-widths and group sizes on the development states. For
distillation, the student state carries the math response and a
reuse-count term carries QA on an unseen pool, with a
budget-dependent bias. Our contributions are (1) the prediction
problem, its admitted inputs, and a development-then-validation design
that separates input value, form value, and transfer range; (2) the
per-method relations, their coefficients, and their independent tests
against same-input and source-free baselines; and (3) an account of
which capabilities and settings the relations cover and where they
stop, with the measurements, registered predictions, and evaluation
code released.
