# Experiment manifest — Stage A reuse map

Snapshot: 2026-09-04. Generated by `analysis/v22_experiment_manifest.py` from local artifacts. This catalogs completed measurements and derived results, including gitignored weights/caches. No model inference, training, scheduler access, or checkpoint deserialization was performed.

Regenerate: `python analysis/v22_experiment_manifest.py`; list inputs without writes: `python analysis/v22_experiment_manifest.py --dry-run`. Run V22 decomposition separately with `python analysis/v22_distill_decomp.py --dry-run` / `--update-law-report`.

Status tags: **HAVE** = existing derived result/report; **REUSABLE** = existing measurement or supporting artifact to reuse; **TO-ANALYZE** = existing evidence needs the named audit/refit; **TO-MEASURE** = absent required measurement, not authorization to run it; **RUNNING** = affirmatively recorded active run. No RUNNING status is asserted here: file presence/absence does not establish job state, and running jobs were not inspected. Reusable does not imply scientific validation or verified binary checkpoint completeness.

All primary loss cells below have math/code/QA unless explicitly noted. L is completion-token weighted CE nats per model-token, and ΔL uses that arm's own dense anchor except explicitly source-referenced distillation. Training D is examples **per domain**; recovery D_R counts supervised causal target tokens. Density and b/16 are nominal compression coordinates, not measured storage or latency. See [MEASUREMENT_AUDIT.md](MEASUREMENT_AUDIT.md).
