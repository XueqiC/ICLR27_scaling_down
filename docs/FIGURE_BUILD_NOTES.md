# Figure build notes

Generated by the four `analysis/plot_fig*.py` scripts. Run each with Python; paths resolve relative to the script, not the working directory. Dependencies: NumPy and matplotlib. Agg backend; CPU only; no model execution or fitting. The scripts only write their PDF/PNG outputs, the Fig. 1 caption, and this document. No existing result JSON, register, or TeX is changed; no mirror is written under `paper/code/analysis/`, following the user's narrower output allowlist.

Fonts use the bold Nimbus Roman / Liberation Serif / Times New Roman setup from `analysis/plot_v9_blocks_appendix.py`, with embedded PDF fonts (fonttype 42), 8 pt minimum at the saved physical size, and PNGs at 300 dpi. Preserve native dimensions when placing these figures to retain that minimum. Pruning/power = blue; quantization/full = orange; distillation/E-only = green; A2 = purple; A1 = teal; median baselines = grey; constant/mean = charcoal. Capability order: math, code, QA. All gain axes use reference MAE minus candidate MAE, positive = candidate better. Fig. 1 instead shows the specified raw loss response (compressed minus dense). Each plot keeps its reported native token units; there is no tokenizer conversion, pooled cross-panel score, fitted smoothing, or invented uncertainty.

Validation: each script checks the relevant numerical identities before saving. Missing optional quantities are printed as LIMITATION and recorded below. Each READ line is an actual JSON read, not merely a cited upstream dependency.
